# 🐺 LyingMan 一键安装

LyingMan 狼人杀网页版一键安装脚本。

无需手动配置 Node.js、Nginx、Systemd 等环境，一条命令即可完成部署。

## ✨ 特性

- 🚀 一键安装 LyingMan
- 📦 自动安装运行环境
- ⚙️ 自动配置 Systemd 服务
- 🌐 自动配置 Nginx
- 🔒 支持域名 + HTTPS
- 🔌 支持 WebSocket / WSS
- 🌍 支持无域名 IP 直接访问
- 🔄 支持服务自动重启
- 🤖 本项目由gpt编写（当然简介也是）（但这一条是我自己写的求star）
